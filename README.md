# DareDash

One minute. One ridiculous challenge. Endless bragging rights.

A mobile-first daily challenge game prototype. Single file, no build step, no dependencies.

## Run

Open `index.html` in any browser (best on a phone), or serve the folder:

    python3 -m http.server 8000

## Features

- Daily Dash (5 challenges, same set for everyone each day) with streaks
- Remix Dash and single-challenge play
- 8 challenges: One-Line Wonder, Worst Luxury Product, Fake Fact Detective, Emoji Brain Dump, Caption Chaos, Impossible Choice, Lightning Thumb, Odd One Out
- XP, levels, stats and history saved locally (localStorage)
- Shareable result grid and friend dare links

## Prototype notes

- Humour scoring uses a playful formula, not a real judge.
- The Impossible Choice crowd split is simulated demo data.
- No backend: no accounts, leaderboards or payments yet.
